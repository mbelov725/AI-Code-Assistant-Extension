# AI Code Assistant Chrome Extension

A simple chrome extension template

## Getting Started
1. Clone the repository
```bash
git clone https://github.com/mbelov725/AI-Code-Assistant-Extension
cd AI-Code-Assistant-Extension
```

2. Install dependencies and build
```bash
npm run install
npm run build
```
This generates a ```dist``` folder in the project directory

3. Upload to Chrome
- Open Chrome and go to <chrome://extensions>
- Toggle on ``Developer mode`` in the top right
- Click ```Load unpacked```
- Select the ```dist``` folder
- Pin the extension to the toolbar

4. If you make any changes and rebuild, reload the extension
